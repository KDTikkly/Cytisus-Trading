Cytisus-Trading 1.1.2

IMPLEMENTATION STATUS

v1.1 Local Paper implementation is complete. Version 1.1.2 adds a local
Algorithm Studio, isolated Quant Worker, compute discovery, versioned projects,
ONNX metadata, and bounded Agent proposals. The app starts in offline fixture mode.
Read-only Longbridge CLI discovery, market fixtures, local caching, and daily
universe snapshots are available. Deterministic Local Paper strategy cycles, factor
research, regime probabilities, and governed strategy capital budgets are
available. Internal netting, partial-fill allocation, the virtual ledger, and
fixture reconciliation are available. Real broker orders and Live execution are
not available.

MACOS

1. Drag "Cytisus-Trading.app" into Applications.
2. Open Cytisus-Trading from Applications.

WINDOWS 11

New packaging is deferred until v1.1.3. No v1.1.2 Windows installer is published.
The prepared future artifact name is "Cytisus-Trading-1.1.2-win11-x64.exe".

NOTES

- The macOS build supports Apple Silicon and Intel Mac computers.
- The minimum macOS version is macOS 14.
- The Windows build supports 64-bit Windows 11.
- Public builds may be unsigned. Only run artifacts from a source you trust.
- Fixture mode makes no network requests and stores no credentials.
- Local CLI mode uses only a separately installed, user-authorized Longbridge CLI.
- Non-sensitive settings, market cache records, universe snapshots, application
  logs, audit events, factor definitions, and trial records are stored locally.
- Local Paper is independent from Longbridge CLI and cannot send real trades.
- The Live Longbridge adapter rejects without starting a process.
- Users supply their own model API and may incur provider charges.
- macOS keys use Keychain Services. Windows keys use CurrentUser DPAPI.
- Model-provider authorization is separate from Longbridge OAuth.
- The Quant Worker requires a user-selected Python interpreter and cannot send orders.
- CPU is the safe fallback; optional accelerators are Ready only after runtime checks.
- Longbridge account fixtures are synthetic. Authentication work remains v1.1.3.
- Never include API keys in issues, logs, screenshots, or bug reports.
- No v1.1.2 DMG, Windows installer, tag, or GitHub Release is produced.
